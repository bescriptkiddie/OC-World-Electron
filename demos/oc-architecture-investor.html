我理解的 OC 架构

先做一个会懂人的 OC，再让成长系统从关系里长出来。

OC World 的架构不是“聊天模型 + 功能模块”，而是三层叠加：前台用 OC 建立长期关系， 后台把真实生活沉淀成成长认知，未来让这个 OC 进入 Agent 世界协作。

一句话给投资人

OC World 是一个陪人一起成长的人生游戏引擎：它不是替人生活，而是把真实生活里的努力变成可见、可复盘、可持续增长的个人资产。

三层架构：关系入口、成长认知、Agent 扩张

这张图刻意不画源码文件，而画投资人真正需要理解的系统骨架。

已落地的主价值 数据飞轮 未来扩张
Layer 01 · Surface

前台是关系，不是系统

用户第一眼看到的是一个 OC：会聊天、会回应、会记得、会陪着自己。复杂成长系统不抢前台。

  • OC 形象与对话是最高频入口
  • 关系阶段让陪伴越来越有连续性
  • 语音、形象、情绪让 AI 从工具变成“在场的人”
  • 用户不用管理成长系统，只需要真实生活和表达
用户感受这个 OC 好像越来越懂我。
商业意义关系入口比效率工具更容易形成长期留存。
Layer 02 · Cognition

后台是成长认知层

每次聊天、复盘、生活信号都会进入后台，被提炼成候选理解、成长证据和下一步练习。

  • ContextSnapshot 汇总今天发生了什么
  • 记忆蒸馏先形成候选，不直接给用户贴标签
  • Growth Insight 识别目标、优势、卡点和偏好
  • Reveal Policy 只在时机合适时温和浮现
  • 用户确认后才进入长期 memory / voice / profile
产品原则确认权在用户，解释权不能完全交给系统。
数据资产记录的不是任务，而是成长证据。
Layer 03 · Expansion

未来是 Agent 世界

当 OC 足够理解用户，它就不只是陪伴者，而能代表用户进入任务、社交和创造网络。

  • Hermes / model gateway 承接更复杂的 Agent 能力
  • 个人 OC 可以带着用户偏好、边界和长期目标行动
  • 多个 OC 未来可以协作、组队、交换成果
  • Agent 世界不是起点，而是长期关系成熟后的扩张层
扩张逻辑先有可信的个人 OC，再有可代理的 Agent。
投资叙事从桌面陪伴入口，走向个人 AI 分身网络。

核心闭环：生活发生以后，OC 把经历翻译成成长

这条闭环是产品价值和数据飞轮的同一条线。

1 生活发生

用户对话、App 使用、任务进展、社交记忆进入系统。

2 OC 接住

OC 先给即时陪伴和情绪理解，不把用户推入管理面板。

3 一起复盘

把混乱经历解释成事实、情绪、卡点和下一步。

4 提炼证据

后台形成 awareness、growth insight、work item 和项目线索。

5 温和浮现

当线索稳定，OC 用一句自然的话邀请用户确认或修正。

6 回到行动

确认后的理解沉淀为长期记忆，并生成更贴身的下一步练习。

Why Now

AI 工具正在变多，但长期关系很稀缺

多数产品只解决“这一刻问答”，OC World 解决“这个人正在变成谁”。关系越久，理解越深，价值越高。

Moat

私有成长数据是复利资产

聊天、记忆、关系、生活信号、用户确认共同构成个人成长画像。它不是冷数据，而是长期陪伴里逐步校准出来的理解。

Scale

Agent 世界是后续网络效应

当每个人都有一个足够懂自己的 OC，OC 之间就可以协作、组队、创造，形成从个人陪伴到任务经济的扩张路径。

现在已经成立的部分

  • 产品OC 关系入口、隐形成长系统、成长证据和温和浮现的方向已经清楚。
  • 技术Electron 桌面壳、聊天主链、ContextSnapshot、记忆蒸馏、统一记忆仓骨架、recall/reveal 已跑通。
  • 体验用户第一屏可以只看到 OC 和对话，后台系统慢慢学习，不把成长系统硬摊开。

下一阶段要补强的部分

  • 治理补 session event stream、writeback ledger、drift guardrails，让长期记忆写入可解释、可回滚。
  • 产品把成长证据结构化，让每次高质量互动都能长出一张可确认的成长记录。
  • 扩张在个人 OC 足够可信之后，再把 Hermes / Agent 世界能力前台化。
